# hxyfront-62013 木结构榫卯构件测绘 · 外业领用台

源提示词编号：8

测绘队外业领用编号牌与测量工具的领用台。建任务时登记建筑、领用人（负责人）和归还时间，再选编号牌与仪器；凭证未归还、仪器校准过期或领取人与负责人不一致的物品留在待领区。收工逐件登记完好、损坏或遗失，缺件任务不能结束；损坏凭证停用后可换新，任务改挂新凭证。

## 分层

- `src/archive.ts` —— 档案：编号牌 / 仪器 / 任务 / 流水的数据结构与台账查询
- `src/rules.ts` —— 规则：领取校验、结束阻断、收工对档案的影响、换凭证条件（纯函数）
- `src/desk.ts` —— 领用台状态流转：页面动作 → 调用规则 → 写回档案并记流水
- `src/App.tsx` + `src/components/` —— 页面：建任务表单、待领区、任务卡（领取 / 收工 / 换新 / 结束）、台账档案

## 技术栈

React + Vite + TypeScript
